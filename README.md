# fifteen-puzzle 十五拼图

4×4 滑块拼图（15-puzzle），纯 Python 标准库实现，带 **A\*** 最优求解器。

## 玩法

把 1–15 按顺序排好，0 为空格。每次把空格相邻的一格滑入空格。

## 用法

```bash
# 交互玩（需要终端）
python -m fifteen_puzzle
# w/a/s/d 移动空格，q 退出

# 自动演示：打乱 + A* 求最优解
python -m fifteen_puzzle auto --games 5 --seed 42 --verbose

# 打乱一局并求解（--show 逐步展示解法）
python -m fifteen_puzzle solve --depth 40 --seed 7 --show
```

## 设计

- 打乱方式：从目标状态随机走 N 步（默认 40），天然保证可解。
- 可解性判定：4×4 棋盘上，逆序数 + 空格所在行（从底往上数，1 起）为奇数 ⟺ 可解。
- 求解器：A\* + 曼哈顿距离启发式，保证最优解；节点上限 300 万，超限则报告失败。

## 已知局限（诚实版）

- A\* 只用曼哈顿启发式：打乱很深（>60 步）或局面很"拧"时可能撞上 300 万节点上限；此时报告失败而非无限等待。
- 打乱步数 ≠ 最优解步数：随机走 40 步里有回头路，实际最优解通常 25–35 步。
- 文本界面，无图形/动画/存档；Python 3.10+，纯标准库。
